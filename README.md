# Better Flow

音声入力デバイスは設定から変更できます。初期値はWindowsのシステム既定マイクです。

モデル一覧にはOpenCode serverが接続済みとして返すproviderのモデルだけを表示します。全providerのカタログは一覧に含めません。

Windows x64向けの音声入力アプリです。入力欄にカーソルを置いて **右Alt** を押して話し、もう一度押すと録音を停止します。ショートカットとAIモードはセットアップ後の同じ画面から変更できます。新規設定ではAIモードがオンで、OpenCode Zen FreeのMuse Spark 1.3 Contributorを選択します。AIモードではOpenCodeのモデルで文章を整え、話し方や敬語・くだけた表現を保ってフィラーや言い直しを調整します。モデル一覧を更新すると、OpenCode Desktopの現在のユーザープロファイルで利用できるモデルやDesktopで追加したモデルから選べます。選んだモデルは設定に保存され、アプリを再起動しても維持されます。Better Flow独自のAPIキー・Base URL設定はありません。言い直しでは変更された内容だけを置き換え、計画など変わらない依頼も残します。箇条書きは発話で複数項目が明確に列挙されたときだけ使います。

テキストを選択してショートカットを押すと、選択文を音声指示で編集する連続セッションを開始します。「英語に翻訳して」「プロンプトとして書いて」などと話すと、認識後に選択文を編集して置き換えます。貼り付け後は置換した文章を再選択するため、そのまま続けて話して編集を重ねられます。もう一度ショートカットを押すと終了します。通常の音声入力は、編集対象の文章を選んでいない状態で使います。

選択文の編集方式は設定から切り替えられ、既定はOpenCodeです。GPT Liveを選ぶと、ChatGPTへサインインしてWebRTC音声で会話し、文章の編集判断はOpenCodeで選択中のモデルが行います。質問や確認には音声で返答し、編集を頼んだときだけ選択範囲を置き換えます。GPT Liveでは音声がChatGPTへ送られます。

連続編集の発話区間判定にはSilero VADを使います。16 kHz音声を512サンプル単位で判定し、発話判定が約256 ms続いてから編集待ち行列へ送るため、短いクリックや雑音だけでAI編集が始まりにくくなります。開始前の約512 msは保持して発話の頭を欠けにくくし、Silero VADの無音判定後も700 ms待ってから区切ります。SileroモデルはEXEに同梱し、初回使用時にSHA-256を確認してアプリデータへ展開します。AI編集後は挿入位置をUI Automationで特定し、キャレットを置いてからネイティブのShift+左キー入力で置換文全体を選択します。選択範囲は入力欄から読み返して確認し、確認できない場合は連続編集を終了します。使用モデルは[Silero VAD](https://github.com/snakers4/silero-vad)のSherpa-ONNX互換ONNX版です。[対応モデルと512サンプル窓の説明](https://k2-fsa.github.io/sherpa/onnx/vad/silero-vad.html)、[Silero VADのMITライセンス](https://github.com/snakers4/silero-vad/blob/master/LICENSE)を同梱しています。

初回画面は白い外周と標準タイトルバーのない角丸フレームレスウィンドウです。上端をドラッグして移動でき、右上のボタンで閉じられます。`Setup` ボタンの文字は黒で表示します。

## 配布と初回セットアップ

配布ファイルは [`dist/Better Flow.exe`](dist/Better%20Flow.exe) です。.NET 8ランタイムを含む自己完結型の単一EXEです。初回のSetupでParakeet日本語モデルとOpenCode CLIを自動で取得します。OpenCodeは公式GitHub Releases APIから最新安定版のWindows x64 baselineアーカイブを取得し、公式SHA-256とファイルサイズを検証してから `%LOCALAPPDATA%\Better Flow\opencode` に配置します。以前のAutoPrompt設定・モデルは引き継ぎます。旧アプリが保存先を使用中なら旧フォルダーをそのまま使い、次回起動時に移行を再試行します。`PATH` 上に既存のOpenCodeがある場合はそれを優先し、アプリ用にPATHやシステム設定は変更しません。音声モデルのセットアップには約1.2 GBの空き容量が必要です。

セットアップ後の画面では完了見出しと録音ボタンを表示せず、設定したショートカットで録音を開始・停止します。セットアップ済みなら、次回起動時はウィンドウを表示せずにタスクトレイへ常駐します。トレイアイコンをダブルクリックするとウィンドウを戻せます。右クリックメニューから完全終了とWindows起動時の自動起動を切り替えられます。音声モデルの読み込みが完了するまでショートカットは登録されません。自動起動はユーザー単位で登録し、起動時はトレイに常駐します。

録音・認識・文章整形中は、画面下中央に背景透過の小さなステータスインジケーターを表示します。表示全体を前のサイズの約半分に縮め、アイコンが切れないようにしました。完了・失敗の表示は処理終了から1秒後に消えます。フルHD・表示倍率100%では画面下端から約12pxの位置で、他のアプリの入力やクリックを妨げません。

AIモードをオンにすると、PATH上の既存OpenCodeを優先して起動します。なければアプリが保存した公式OpenCode CLIを使います。OpenCodeは同じWindowsユーザーのOpenCode Desktopと共通の設定・認証プロファイルを参照します。Desktopでモデルを追加・接続した後、Better Flowの一覧を更新してください。モデルの接続設定や認証はOpenCode側で管理し、Better FlowはOpenCodeの設定ファイルや認証情報を読み書きしません。初回サインインが必要なモデルは、OpenCode Desktop側で認証してください。認証が未完了でも、既定の文字起こしモードは利用できます。

## データの扱い

- 音声の録音と文字起こしはPC内で行い、音声自体は送信しません。
- 既定の文字起こしモードでは音声・文字起こしともPC内だけで処理します。
- AIモードの場合だけ、通常の音声入力の文字起こし、または選択文と音声指示をローカルのOpenCode server経由で選択中のモデルへ送信し、生成結果を受信します。音声自体は送信しません。
- GPT Liveを選んだ選択文編集では、マイク音声をWebRTCでChatGPTへ送り、会話中の文字起こしをOpenCode経由で選択中のモデルへ渡します。編集結果は選択範囲に反映し、GPT Liveからの音声応答を再生します。
- OpenCode Desktopで選んだ接続先ごとの利用規約とデータ利用条件が適用されます。[OpenCode Zenのモデル・データ利用条件](https://docs.opencode.ai/docs/zen/)
- OpenCode Zenでは一時セッションを作成し、変換後に削除します。サーバーはloopbackだけで待ち受けます。既定のPlanエージェントと「ツールを使わず文章だけを返す」指示で文章変換を依頼します。
- AIモードで使うモデルと認証はOpenCode Desktopのユーザープロファイルに従います。Better FlowからOpenCode設定内のモデル一覧を読み、選択したprovider/model IDをローカルOpenCode serverへ渡します。
- OpenCodeのユーザー設定・認証ファイルは読み書きせず、OpenCode自身が通常どおり参照します。

## 音声認識モデルの根拠

公開[FLEURS日本語ベンチマーク](https://github.com/cm-nakamura-shogo/japanese-asr-l40s-benchmark)で、Parakeet TDT-CTC 0.6B JAはCER 5.94%、Whisper Large V3 Turboは4.81%でした。Parakeetの方が1.13ポイント高い誤り率です。この比較は公開測定を選定根拠にしたもので、このアプリで独自の精度テストは行っていません。ベンチマーク測定はNeMo版の重みであり、アプリが取得するINT8 ONNX版の精度を保証しません。

## アイコン

ルートの `icon.svg` から `Assets/BetterFlow.png` と複数サイズの `Assets/BetterFlow.ico` を生成します。PNGは画面内、ICOはウィンドウ・タスクバー・EXEに使用します。再生成する場合は `pwsh -NoProfile -File tools/Generate-Icons.ps1` を実行してください。
